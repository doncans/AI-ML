# AI-ML

A hands-on collection of AI/ML examples for learning core machine learning concepts with Python and scikit-learn.

## Examples

| # | Topic | File | Concepts |
|---|-------|------|----------|
| 1 | **Linear Regression** | `examples/01_linear_regression.py` | Regression, train/test split, MSE, R² score, residual analysis |
| 2 | **Classification** | `examples/02_classification.py` | Decision Trees, Random Forest, KNN, confusion matrix, feature importance |
| 3 | **Clustering** | `examples/03_clustering.py` | K-Means, elbow method, feature scaling, unsupervised learning |
| 4 | **Neural Network** | `examples/04_neural_network.py` | MLP classifier, digit recognition, training curves, confidence analysis |

## Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Run any example
python examples/01_linear_regression.py
python examples/02_classification.py
python examples/03_clustering.py
python examples/04_neural_network.py
```

## What You'll Learn

- **Supervised Learning**: Predicting continuous values (regression) and categories (classification)
- **Unsupervised Learning**: Finding hidden patterns in data without labels (clustering)
- **Neural Networks**: Building multi-layer perceptrons for image recognition
- **Model Evaluation**: Metrics like accuracy, MSE, R², confusion matrices
- **Data Visualization**: Plotting results with matplotlib and seaborn

## Requirements

- Python 3.9+
- See `requirements.txt` for package dependencies
